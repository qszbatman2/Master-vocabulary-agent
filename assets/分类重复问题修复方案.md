# 分类重复问题修复方案

## 问题描述

### 问题现象
- 生产环境数据库中 `vocabulary_categories` 表存在重复分类
- API返回32个分类，但实际只有16个唯一分类
- 导致前端分类筛选器显示重复选项

### 数据统计
- 总分类数（含重复）：32个
- 唯一分类数：16个
- 重复分类数：16个

---

## 解决方案

### 方案A：API层去重（已完成）

**修改文件：**
- `CozeProject/src/app/api/categories/route.ts`

**核心代码：**
```typescript
// 去重：保留每个分类名称的最小ID
const nameToCategory = new Map<string, any>();
categories?.forEach(cat => {
  const existing = nameToCategory.get(cat.name);
  if (!existing || cat.id < existing.id) {
    nameToCategory.set(cat.name, cat);
  }
});

const uniqueCategories = Array.from(nameToCategory.values())
  .sort((a, b) => a.id - b.id);
```

**优点：**
- 立即生效，无需修改数据库
- 前端立即看到正确结果

**缺点：**
- 数据库中仍有重复数据
- 不是根本解决方案

### 方案B：数据库层去重（推荐执行）

#### 步骤1：检查重复分类

```sql
-- 查看所有重复分类及其数量
SELECT name, COUNT(*) as count, MIN(id) as min_id, MAX(id) as max_id
FROM vocabulary_categories
GROUP BY name
HAVING COUNT(*) > 1
ORDER BY count DESC;
```

#### 步骤2：更新单词表的分类关联

```sql
-- 先备份数据（可选）
CREATE TABLE vocabulary_words_backup AS SELECT * FROM vocabulary_words;

-- 更新单词表，将重复分类ID映射到最小ID
UPDATE vocabulary_words vw
SET category_id = (
  SELECT MIN(id)
  FROM vocabulary_categories
  WHERE name = (SELECT name FROM vocabulary_categories WHERE id = vw.category_id)
)
WHERE category_id NOT IN (
  SELECT MIN(id)
  FROM vocabulary_categories
  GROUP BY name
);
```

#### 步骤3：删除重复分类

```sql
-- 删除重复分类（保留每个名称的最小ID）
DELETE FROM vocabulary_categories
WHERE id NOT IN (
  SELECT MIN(id)
  FROM vocabulary_categories
  GROUP BY name
);
```

#### 步骤4：验证结果

```sql
-- 查看所有分类
SELECT * FROM vocabulary_categories ORDER BY id;

-- 统计分类数量
SELECT COUNT(*) as total_categories FROM vocabulary_categories;

-- 检查是否还有重复
SELECT name, COUNT(*) as count
FROM vocabulary_categories
GROUP BY name
HAVING COUNT(*) > 1;
```
