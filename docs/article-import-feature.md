# 从文章添加生词功能 - 功能说明与技术架构

## 功能概述

「从文章添加生词」功能允许用户将英文文章粘贴到系统中，智能解析文章内容，识别单词并支持用户选择生词添加到个人词库。该功能支持词形还原、上下文例句保存，并能与现有词库进行关联。

---

## 功能特性

### 1. 文章解析与分词
- 智能识别英文文章中的单词、标点和换行
- 保留文章原始格式，支持多段落显示
- 实时统计文章句子数和单词数

### 2. 词形还原 (Lemmatization)
- **本地优先策略**：使用 NPM 库 `lemmatizer` + 自定义不规则词库
- **不规则词库**：内置 150+ 常见不规则动词变化（如 went→go, was→be）
- **规则处理**：支持常见词形变化规则
  - 复数：-es, -ies, -ves
  - 过去式：-ed
  - 进行时：-ing
  - 比较级/最高级：-er, -est
- **LLM 兜底**：可选使用豆包模型进行复杂词形还原

### 3. 词库关联检测
- 实时检测单词是否已在系统词库中
- 绿色高亮显示已存在词库的单词
- 白色显示新词，便于识别

### 4. 生词选择交互
- 点击单词即可标记/取消标记为生词
- 已选单词显示粉色渐变背景和确认标记
- 支持清空选择、重新编辑
- 实时统计已选数量和新词数量

### 5. 上下文例句保存
- 自动提取单词所在句子作为上下文
- 第一个例句自动设为主例句（`is_primary: true`）
- 支持同一单词多次收录不同例句

### 6. 数据持久化
- 保存文章来源记录（标题+内容）
- 创建/关联词库词条
- 创建用户词状态记录
- 创建上下文例句记录

### 核心模块说明

#### 1. 词形还原模块 (`src/lib/lemma-utils.ts`)

```
┌─────────────────────────────────────────────────────────────────┐
│                      词形还原流程                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   输入: "went"                                                  │
│      │                                                          │
│      ↓                                                          │
│   ┌─────────────────────────────────┐                          │
│   │ 1. 检查不规则词库 (IRREGULAR_LEMMAS) │                       │
│   │    went → go ✓                  │                          │
│   └─────────────────────────────────┘                          │
│      │ 找到 → 返回 "go"                                          │
│      │ 未找到 → 继续                                             │
│      ↓                                                          │
│   ┌─────────────────────────────────┐                          │
│   │ 2. 使用 lemmatizer NPM 库        │                          │
│   │    running → run                │                          │
│   └─────────────────────────────────┘                          │
│      │ 成功 → 返回结果                                            │
│      │ 失败/无变化 → 继续                                         │
│      ↓                                                          │
│   ┌─────────────────────────────────┐                          │
│   │ 3. 应用规则处理                  │                          │
│   │    -es, -ies, -ves              │                          │
│   │    -ed, -ing                    │                          │
│   │    -er, -est, -s                │                          │
│   └─────────────────────────────────┘                          │
│      │                                                          │
│      ↓                                                          │
│   返回小写形式                                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**导出函数：**

| 函数名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `lemmatizeLocal(word)` | 单词字符串 | 词根 | 本地词形还原（无网络请求） |
| `lemmatizeWithLLM(word)` | 单词字符串 | Promise<string> | LLM 词形还原（兜底方案） |
| `smartLemmatize(word, useLLM?)` | 单词, 是否用LLM | Promise<string> | 智能词形还原 |
| `batchLemmatize(words[])` | 单词数组 | Map<原词, 词根> | 批量词形还原 |

## 与练习模式的集成

### 主动收录词识别

练习模式通过 `has_user_context` 字段识别主动收录词：

```typescript
interface Question {
  // ...
  has_user_context?: boolean;  // 是否有用户收录的例句
}
```

### 练习模式特殊处理

1. **优先展示**：每轮练习前5题优先展示主动收录词
2. **标签显示**：题目卡片显示粉色「主动收录」标签
3. **中文隐藏**：主动收录词的例句不显示中文翻译
4. **粗体强调**：主动收录词在例句中以白色粗体显示，其他文字为灰色

### 练习模式筛选

支持 `filter=collected` 筛选仅练习主动收录的单词：

```
GET /api/practice?category=all&filter=collected
```

## 技术要点

### 1. 性能优化

- **批量查询**：词库关联检测使用分批查询（每批100词），避免 SQL 过长
- **本地词形还原**：优先使用本地 NPM 库，避免 API 调用延迟
- **增量更新**：已存在词库的单词直接关联，不重复创建

### 2. 容错处理

- 词形还原失败时返回原词小写形式
- LLM 调用失败时自动降级到本地处理
- 无释义单词使用占位文本「待补充释义」

### 3. 用户体验

- 三步流程清晰指引
- 实时统计已选数量
- 颜色区分已存在/新词
- 支持返回修改和重新添加

## 扩展方向

1. **批量导入**：支持从 URL 导入文章内容
2. **PDF 解析**：支持上传 PDF 文件提取文本
3. **AI 释义**：使用 LLM 自动生成缺失单词的释义
4. **智能推荐**：基于文章难度推荐适合的单词学习
5. **学习统计**：统计各来源文章的单词掌握情况
